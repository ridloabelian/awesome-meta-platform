## MCP Servers (AI Agents)

Model Context Protocol servers that expose Meta APIs to LLM agents (Claude, Cursor, ChatGPT).

- [NotFair](https://github.com/nowork-studio/NotFair) - Open-source Claude Code skills for SEO, GEO, Google Ads & Meta Ads.
- [pipeboard-co/meta-ads-mcp](https://github.com/pipeboard-co/meta-ads-mcp) - Meta Ads (Facebook/Instagram) MCP server for Claude, ChatGPT, Perplexity & Cursor.
- [google-meta-ads-ga4-mcp](https://github.com/irinabuht12-oss/google-meta-ads-ga4-mcp) - Unified MCP server for Google Ads, Meta Ads & GA4.
- [meta-ads-analyzer](https://github.com/mathiaschu/meta-ads-analyzer) - Meta Ads analyzer skill + MCP for Claude Code (Breakdown/Learning-phase insights).
- [amekala/ads-mcp](https://github.com/amekala/ads-mcp) - MCP server managing campaigns across Google, Meta & LinkedIn Ads.
- [mikusnuz/meta-ads-mcp](https://github.com/mikusnuz/meta-ads-mcp) - MCP server for Meta Marketing API v25.0 — 135 tools for FB & IG ads.
- [markifact-mcp](https://github.com/markifact/markifact-mcp) - MCP for Google Ads, Meta Ads, GA4, TikTok & LinkedIn Ads.
- [armavita-meta-ads-mcp](https://github.com/EfrainTorres/armavita-meta-ads-mcp) - IG & FB MCP for Meta Marketing API v25 with secure token redaction.
- [oliverames/meta-mcp-server](https://github.com/oliverames/meta-mcp-server) - 200+ tool MCP server covering Meta's business platform (archived).
- [facebook-ads-library-mcp](https://github.com/proxy-intell/facebook-ads-library-mcp) - MCP server querying Facebook's public Ad Library.

## Ad Library & Research

Tools for analyzing public ads (Meta Ad Library). Respect Meta's terms & rate limits.

- [facebook_ad_library](https://github.com/Lejo1/facebook_ad_library) - Copy of ads from the Facebook Ad Library API.
- [MetaAdsCollector](https://github.com/promisingcoder/MetaAdsCollector) - Collect ads from the Meta Ad Library, no API key required.
- [meta-ads-scraper](https://github.com/athm793/meta-ads-scraper) - Self-hosted Ad Library research tool (keyword/advertiser).
- [fb_ad_scraper](https://github.com/ChrisFeldmeier/fb_ad_scraper) - Meta Ads Library scraper.
- [Meta-Ads-Spy-Claude-Code-Airtable](https://github.com/krusemediallc/Meta-Ads-Spy-Claude-Code-Airtable) - Pull competitor ads from Meta Ad Library into Airtable via Claude Code.
- [AdsOnSheets](https://github.com/konkomaji/AdsOnSheets) - Meta Ads monitoring dashboard built on Google Sheets.
